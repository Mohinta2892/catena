# Convert WASP to CREMI format: `convert_wasp_to_CREMI.py`

To test synful on WASP datasets, we have to first convert it into the CREMI format.
For us CREMI data format is the standardised of form for all synapse predictions.
The WASP data in CREMI format is currently [here](https://www.dropbox.com/scl/fo/e4c47npukcvrmuu0a5d6h/AOivboXPljDAkXRXHq9WHxA?rlkey=t2b11g1kqca42oy56l59i56nl&st=kovyixyq&dl=0)
