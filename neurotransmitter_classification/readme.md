### Neurotransmitter Classification with Synister
This is very initial reimplementation of the Synister (from its newer dev branch).
It has been restructured to work in local which have been carefully curated from publicly
available adult fly datasets. These local datasets are much smaller in size, with the biggest dataset containing a 1000 examples for `acetylcholine`, `serotonin`, `dopamine`, `glutamate`, `gaba`, `octopamine`, `tyramine`.
